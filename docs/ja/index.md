# はじめに

tuna は、コーディングエージェントと一緒に働くために作られた、macOS、Windows、Linux 向けのターミナルです。Claude Code、Codex、開発サーバー、テストウォッチャーを、それぞれ独立した**セッション**で動かします。tuna はセッションをプロジェクトごとにサイドバーにまとめ、どれが作業中で、どれが対応待ちで、どれが完了したかを示します。

## ウインドウより長生きするセッション

セッションはアプリの中では動いていません。tuna が代わりに起動する小さなデーモン **tunad** の中で動いています。tuna を終了しても、すべては動き続けます。もう一度開けば、すべてのセッション、ペイン、スクロールバックが元のままです。

::: tip
tuna を終了（<kbd>⌘</kbd> <kbd>Q</kbd>）しても、セッションは動き続けます。すべて終えるには、**tuna › 終了してすべてのセッションを終える…**（<kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>Q</kbd>）を使います。
:::

## エージェントのために

- **状態がひと目でわかる。** 各ペインは*作業中*、*待機中*、*アイドル*、*エラー*、*終了*のいずれかです。あなたを必要としているセッションは目立ち、<kbd>⌘</kbd> <kbd>J</kbd> でまっすぐそこへ移動できます。
- **大事なときに通知。** ほかの場所を見ている間にエージェントが完了したとき、失敗したとき、あなたの対応を待っているときに、tuna が通知します。
- **エージェントが操作できる CLI。** `tuna` コマンドで、セッションの開始、ペインの分割、入力の送信、完了の待機、画面の読み取りができます。エージェントは自分の横で作業を動かし、自分の進捗を報告できます。
- **中身は Ghostty。** ターミナルの描画は libghostty なので、Ghostty のテーマ、フォント、設定キーが期待どおりに動きます。
